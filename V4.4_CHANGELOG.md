# v4.4 — Advanced Animation System

## Summary
Complete animation overhaul. Every below-fold section now has directional reveals, hover effects, and at least one signature animation. Added 3 new "wow" sections: cinematic Ken-Burns hero strip, brand marquee, and recent-fixes auto-carousel.

## ✅ All Requested Animations Delivered

### 1. Automatic Sliders / Carousels
- **`RecentFixesCarousel`** — CSS scroll-snap horizontal carousel showing 8 recent fixes. Native browser swipe + keyboard nav, zero JS.
- **`auto-slider` / `auto-slider-track`** CSS classes — full-bleed automatic slider that cycles every ~6 seconds, pauses on hover.
- **`BrandMarquee`** — infinite scrolling brand logos with `marquee-track-slow`, edge-faded via `marquee-mask`.

### 2. Background "Video" Effects (Ken Burns)
- **`CinematicStrip`** — full-bleed section using `kb-frame kb-zoom-in kb-overlay`. Background slowly zooms + pans 20s loop. Dark gradient overlay keeps text readable.
- **`DownloadCTASection`** — uses `kb-zoom-in kb-overlay-brand` (orange-tinted overlay) for branded "video" feel.
- **6 KB animations available**: `kb-zoom-in`, `kb-zoom-out`, `kb-pan-left`, `kb-pan-right`, plus 2 overlay variants for text contrast.

### 3. Hover Effects
- **`spotlight`** — radial gradient follows cursor inside section (mouse tracking via ScrollRevealProvider)
- **`card-hover-lift`** — multilayer lift with orange/red shadow halo
- **`card-tilt`** — 3D perspective rotation on hover
- **`border-trace`** — animated conic-gradient border that traces around the card
- **`img-hover-zoom`** — gentle 1.08x scale on image hover

### 4. Text Animations
- **`text-gradient-sweep`** — orange→red→peach gradient that sweeps across headlines (3s loop) — applied to most H2s
- **`text-stagger`** — letter-by-letter rise animation
- **`typewriter`** — typewriter effect with blinking orange cursor
- **`text-glitch`** — RGB-split glitch on hover (rare, used sparingly)

### 5. Directional Reveals (left/right/top/bottom)
- **`reveal-from-left`** — slides in from -60px X
- **`reveal-from-right`** — slides in from +60px X
- **`reveal-from-top`** — drops in from -50px Y
- **`reveal-from-bottom`** — rises from +50px Y
- **`reveal-zoom`** — scales from 0.85
- **`reveal-rotate`** — rotates -8deg + drops in
- **`data-stagger="1..8"`** attribute — adds 0.05–0.7s delay for grid staggering
- All triggered by `IntersectionObserver` in `ScrollRevealProvider` (one-shot, unobserves after first reveal)

### 6. Other Polish
- Glass-morphism cards everywhere with hover glow
- Glow-trace borders on tilt cards
- Pulse-dot indicators in social-proof and live-status sections
- Edge-faded marquee containers via mask-image
- All animations respect `prefers-reduced-motion`

## Performance
- All animations are **CSS-only** — no JS animation libraries
- IntersectionObserver `unobserve()` after first reveal — zero ongoing cost
- Marquee/carousel animations use `transform` only (GPU-accelerated)
- Spotlight mouse tracking uses passive listener + CSS variables
- `prefers-reduced-motion` disables all animations site-wide
- Page weight increase: ~9KB CSS gzipped
