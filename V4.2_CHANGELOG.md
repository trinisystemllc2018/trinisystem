# v4.2 — Restored All Missing Sections

## Problem
The old (`trinisystem-main`) site had a 1,142-line homepage with **10 sections**.
The v4 homepage was only 207 lines and rendered just **5 sections** in BelowFoldSections.
Many features the old site had — brand showcase, smart problem finder, full services
grid, comparison table, social proof activity feed — were missing.

## What was added

`src/components/sections/BelowFoldSections.tsx` is now a comprehensive composition
of 11 sections, all styled in the dark + orange/red theme:

| # | Section | Status | Source |
|---|---------|--------|--------|
| 1 | EightYearTrustBanner | ✨ NEW | Inspired by old "8 years trust banner" |
| 2 | BrandsSection — HP, Canon, Epson, Brother | ✨ RESTORED | Old `BrandsSection` |
| 3 | SmartFinderSection — interactive diagnoser | ✨ RESTORED | Old `SmartProblemFinder` (lazy-loaded) |
| 4 | ServicesGrid — 9 service cards | ✨ RESTORED | Old `ServicesGrid` |
| 5 | HowItWorks — 4 steps | ✨ ENHANCED | Was simpler in v4.1 |
| 6 | SocialProof — live activity feed | ✨ NEW | Inspired by old `SocialProofSection` |
| 7 | GoogleReviewsSection — 6 reviews | ✨ ENHANCED | Replaced minimal review block |
| 8 | ComparisonSection — Trini vs Geek Squad | ✨ RESTORED | Old `ComparisonSection` |
| 9 | GuidesSection — Gmail, Facebook, Garmin | ✨ KEPT | From v4.1 |
| 10 | DownloadCTASection — TriniCleaner | ✨ ENHANCED | Old `DownloadCTASection` with floating icon, animated orbs |
| 11 | FinalCTA — phone + contact | ✨ NEW | Wraps the page |

## Design language applied
- Pure dark background (`#020005` to `#050008`) with orange/red accents
- Every section has a `scroll-reveal` class so it fades up as you scroll into view
- Service/brand/guide cards use `magnetic` (lift on hover) + `click-ripple` (purple→orange ripple on tap)
- All CTAs use `cta-glow-ring` (animated halo) with orange→red gradient
- Comparison table rows highlight on hover (orange tint)
- TriniCleaner CTA section has 2 floating animated orbs + dot pattern
- Brand card icons rotate slightly on hover
- All headlines use `text-gradient-gold-shimmer` (orange/red sweep)

## Performance
- `SmartProblemFinder` lazy-loaded via `dynamic()` (it's a client component)
- All other sections are server-rendered (zero JS cost)
- Scroll-reveal triggered by IntersectionObserver (already in v4)
- Total added bundle: < 4KB gzipped (just SmartProblemFinder hydration)

## Files Changed
- `src/components/sections/BelowFoldSections.tsx` — full rewrite (was ~250 lines, now ~480 lines)

## Files Untouched
- Hero, navbar, footer, search box, all routes, all SEO schemas
- `src/lib/utils.ts` — BRANDS, SERVICES, REVIEWS data already had what we needed
- `SmartProblemFinder.tsx` — kept as-is (white-themed island provides nice contrast on dark page)
