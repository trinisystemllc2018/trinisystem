# v3.2 — Pure Black Theme

## What changed (from v3.1)

### 🎨 Pure Black Background — No Grid Checks

**Removed:**
- ❌ Grid pattern (`.bg-grid` is now a no-op)
- ❌ Blue navy hero gradient (`#0d2448`, `#060f20`)
- ❌ Strong blue orb (top-left)
- ❌ Cyan orb (top-right)
- ❌ Blue band in aurora gradient
- ❌ Blue navy footer header strip
- ❌ Gray-950 footer base

**Replaced with:**
- ✅ Pure `#000000` background everywhere
- ✅ Subtle amber + faint violet glow on hero (very low opacity, 10–13%)
- ✅ All orbs are now amber/gold tones (the dimmer purple stays for depth)
- ✅ Aurora is amber-and-violet only — no blue/cyan
- ✅ Footer header is dark amber-tinted (was bright blue)

### 📁 Files Changed

| File | Change |
|------|--------|
| `src/app/layout.tsx` | `body className="bg-black"` (was `bg-[#050d1a]`) |
| `src/app/globals.css` | `.bg-hero` → pure black with amber tint only |
| `src/app/globals.css` | `.bg-grid` → no grid lines (kept class so existing markup doesn't break) |
| `src/app/globals.css` | `.bg-section-dark` & `.bg-section-navy` → pure black gradients |
| `src/app/globals.css` | All hero orbs recolored from blue/cyan to amber |
| `src/app/globals.css` | Aurora gradient reduced to amber + violet only |
| `src/components/layout/Navbar.tsx` | Pure `#000000` background |
| `src/components/layout/Footer.tsx` | `bg-black` (was `bg-gray-950`) |
| `src/components/layout/Footer.tsx` | Header strip → amber-tinted (was blue) |
| `src/components/sections/BelowFoldSections.tsx` | "How it works" → pure black |

### Visual Result
- Premium, theatrical pure black canvas
- Gold/amber as the only dominant accent color
- Subtle warm glow on hero — atmosphere without distraction
- No grid lines, no blue tones anywhere
- Service cards still have their per-card colors (blue, purple, red, etc.) as accent on hover — but the canvas they sit on is pure black

### Performance
- Slightly faster: removing the grid lines removed two CSS gradient images per page paint
- All other characteristics unchanged from v3.1
