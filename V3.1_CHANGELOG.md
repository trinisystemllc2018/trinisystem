# v3.1 — Hero 3D Upgrade

## What changed (from v3.0)

### 🐛 Critical Bug Fix
**Body background was white**, which caused the hero text "Your Tech Problem," to be invisible (white-on-white) and the trust pills/quick-fix chips to disappear into the background.

**Fixed in `src/app/layout.tsx`:**
```tsx
// BEFORE (broken)
<body className="bg-white text-gray-900 antialiased font-sans">

// AFTER (fixed)
<body className="bg-[#050d1a] text-white antialiased font-sans">
```

### ✨ Visual 3D Upgrades

**1. Aurora ribbon background** — animated conic gradient that slowly rotates behind the hero, mixing blue/purple/amber/cyan light. Uses `mix-blend-mode: screen` for premium glow.

**2. Bigger, brighter orbs** — opacity bumped from 0.07–0.15 → 0.35–0.55, sizes increased, and `mix-blend-mode: screen` added so they layer naturally.

**3. Multi-layer hero background** — the `.bg-hero` class now stacks 4 radial gradients (blue top-left, amber top-right, purple bottom, dark navy base) for true depth instead of a flat color.

**4. Grid overlay with mask** — the subtle grid lines now fade out at the edges via `mask-image: radial-gradient(...)`, focusing the eye on the center.

**5. Animated shimmer headline** — "Fixed Today." now uses `text-gradient-gold-shimmer` (4-stop gold gradient that slowly sweeps across).

**6. Glass-morphism cards** — status badge, secondary CTA, and trust stats now use a `.glass-card` style: 16px backdrop-blur + subtle white border + inset highlight.

**7. CTA glow ring** — primary phone button has a pulsing gradient halo via `.cta-glow-ring` (animated gradient blur ring behind the button).

**8. 3D trust stats grid** — 4 stat boxes (4.9★, 47, 20+, 50) now sit in glass cards with text-shadow depth, instead of floating naked text.

**9. Bigger pulse dot** — the "Technician Available Now" indicator uses a custom `.pulse-dot` with proper expanding ring (3x scale ping).

### 📁 Files Changed
- `src/app/layout.tsx` — body className fix
- `src/app/globals.css` — new 3D utility classes appended (.aurora, .glass-card, .pulse-dot, .text-gradient-gold-shimmer, .cta-glow-ring, .stat-3d, etc.)
- `src/app/globals.css` — `.bg-hero` upgraded to multi-radial gradient
- `src/app/globals.css` — orb opacity/blur/size bumped
- `src/app/page.tsx` — hero block restructured with new classes

### Visual Result
- Hero now has obvious depth and atmosphere
- All text is readable
- The phone CTA pulses with a colored halo
- Trust stats look premium instead of floating
- Aurora gradient creates motion without performance cost (CSS-only)
- Still 0 client JS added — same LCP target

### Performance Impact
- **Zero new JavaScript** — all effects are CSS
- Aurora animation uses `transform: rotate()` only (GPU-accelerated)
- Orbs use `mix-blend-mode: screen` (also GPU)
- Glass-card backdrop-blur is the only new render cost; isolated to ~6 elements
- LCP should remain under 2s on mobile
